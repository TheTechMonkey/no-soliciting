# No Soliciting

No Soliciting keeps wandering traders and their trader llamas out of selected areas.

Place a No Soliciting Sign, then sneak-right-click it with a stick to open its settings. The sign can protect a radius of 8, 16, 32, or 64 blocks. Use the Show Boundary button to display the protected area for one minute.

The mod prevents wandering traders from spawning inside protected areas and directs wandering traders and trader llamas away if they enter one. It does not affect villagers, animals, monsters, or other entities.

No Soliciting requires Fabric Loader and Fabric API on both the server and client.
